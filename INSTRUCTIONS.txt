Telegram Manager - Boshqarish va Fon Rejimida Ishlatish (Systemd)
================================================================

1. Bir martalik o'rnatish (Service ni faollashtirish va autorun qilish):
   cd /home/server/Projects/tg-manager
   ./install_service.sh

2. Qulay boshqaruv skripti orqali boshqarish:
   ./manage.sh status     # Bot holatini ko'rish
   ./manage.sh start      # Ishga tushirish
   ./manage.sh stop       # To'xtatish
   ./manage.sh restart    # Qayta ishga tushirish (kod yangilanganda)
   ./manage.sh logs       # Jonli loglarni kuzatish (Ctrl+C bilan chiqish)

3. Standart systemctl buyruqlari orqali boshqarish:
   sudo systemctl status tg-manager
   sudo systemctl start tg-manager
   sudo systemctl stop tg-manager
   sudo systemctl restart tg-manager
   sudo journalctl -u tg-manager -f
